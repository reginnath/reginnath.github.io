PROJECT 01

Sales Data Analytics

Overview

An end-to-end sales data analytics project following the CRISP-DM framework, covering data preparation, exploratory analysis, statistical testing, A/B testing, and predictive modeling.

Objective

To explore sales data, identify meaningful patterns, evaluate differences between sales channels, and build a classification model to analyze factors associated with online and retail sales.

Workflow

Data Cleaning EDA Statistical Testing A/B Testing Machine Learning Model Evaluation

Key Takeaways

  • Revenue showed a statistically significant difference between online and retail sales channels.
  • Profit did not show a statistically significant difference between the two channels.
  • The classification model showed moderate predictive performance and signs of overfitting.

Tech Stack

Python Pandas NumPy Matplotlib Seaborn SciPy Scikit-learn
